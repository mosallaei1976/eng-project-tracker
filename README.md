# Samaneh Nezam CRM PWA (سامانه مدیریت پروژه‌های دفاتر مهندسی)

Offline-first Progressive Web App (PWA) designed specifically for engineering offices and members of the Engineering Organization (سازمان نظام مهندسی) to manage projects, specialties, notes, and local backups without requiring an internet connection.

---

## 🌟 Features / ویژگی‌ها

- **Offline-First Architecture**: Fully functional without internet access using browser local storage and Service Workers.
- **Project & Case Tracking**: Manage engineering files, client details, and municipal project statuses seamlessly.
- **8 Engineering Specialties**: Support for structural, architectural, electrical, mechanical, and other specialized design/supervision fields.
- **Quick Notes & Local Backup**: Instant note-taking per project with robust JSON backup and restore capabilities.
- **PWA Installable**: Install directly on mobile devices (Android/iOS) and desktop browsers as a standalone application.
- **Zero Dependencies**: Lightweight single-file implementation with no complex backend or database setup required.

---

## 🛠️ Technical Stack / تکنولوژی‌های ساخت

- **Frontend**: Pure HTML5, CSS3, and Modern Vanilla JavaScript (Single-File Architecture).
- **Storage**: Browser `localStorage` for secure local data persistence.
- **PWA**: Service Worker (`sw.js`) and Web App Manifest for caching and offline support.
- **Design**: Minimalist, responsive, RTL Persian UI built with Vazirmatn typography and a professional blue theme.

---

## 🚀 Getting Started & Installation / راه‌اندازی و نصب

1. Clone or download this repository.
2. Serve the files via any static web server or host directly on **GitHub Pages**.
3. Open the app in your browser and click **"Add to Home Screen"** or install via the browser prompt.
